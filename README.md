# Slash

[TakoEngine](https://github.com/KyouGenSo/TakoEngine) で作っているゲーム。

## 始め方

要る物：Windows 10 / 11（64 ビット）、DirectX 12 に対応した GPU、Visual Studio 2026 の「C++ によるデスクトップ開発」。

1. このリポジトリを clone する（zip で落としてもよい）
2. ルートの `UpdateEngine.bat` を実行する。エンジンが `Engine\TakoEngine` に入る（約 75 MB のダウンロード）
3. `Slash.sln` を Visual Studio で開き、F5 でエディタを起動する

エンジンを新しくするときは、もう一度 `UpdateEngine.bat` を実行する。
